# Python Lab: Conditional Statements and Decision-Making

This repository contains Python programs developed for the laboratory assignment in the **Introduction to Python Programming** course at **Qarabağ Üniversitesi**[cite: 4]. The project demonstrates the practical application of conditional statements (`if`, `elif`, `else`), logical operators, input validation, and interactive decision-making algorithms[cite: 4].

---

## 📁 Repository Structure

* `BMI.py`: Task 1 - Body Mass Index (BMI) Calculator that evaluates health categories based on weight and height[cite: 2, 4].
* `zodiac.py`: Task 2 - Chinese Zodiac Calculator that determines the zodiac sign using a 12-year cycle[cite: 3, 4].
* `birthday game.py`: Task 3 - Interactive Birthday Guessing Game that calculates the user's birth day using predefined number sets[cite: 1, 4].

---

## 🚀 Applications Overview

### 1. Body Mass Index (BMI) Calculator (`BMI.py`)
* Computes BMI using the formula: $\text{BMI} = \frac{\text{weight}}{\text{height}^2}$[cite: 2, 4].
* Includes input validation to prevent negative or zero values for weight and height[cite: 2].
* Classifies results into standard ranges: Underweight (below 18.5), Normal Weight (18.5 - 24.9), Overweight (25.0 - 29.9), and Obese (30.0 and above)[cite: 2, 4].
* Features a loop option allowing users to repeat calculations without restarting the program[cite: 2, 4].

### 2. Chinese Zodiac Calculator (`zodiac.py`)
* Operates on a 12-year cycle where each year corresponds to a specific animal[cite: 3, 4].
* Determines the animal sign using the modulo operation (`year % 12`)[cite: 3, 4].
* Validates user input to ensure the birth year falls within an acceptable range[cite: 3].
* Supports all twelve zodiac signs: Monkey, Rooster, Dog, Pig, Rat, Ox, Tiger, Rabbit, Dragon, Snake, Horse, and Sheep[cite: 3, 4].

### 3. Birthday Guessing Game (`birthday game.py`)
* Displays five distinct numerical sets to the user[cite: 1, 4].
* Asks whether the birth date appears in each set, taking binary inputs (`1` for yes, `0` for no)[cite: 1, 4].
* Calculates and reveals the exact birth day dynamically without asking directly for the date[cite: 1, 4].
